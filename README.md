# Video Projects · AI-кадры и видео

`Video_Projects_Local.html` — локальный редактор сцен и титров для DaVinci Resolve (.drt).
С версии 5.3 в нём есть блок **«AI-кадры и видео»**:

1. **Кадр** — по тексту сцены (или своему описанию) через OpenAI Images (`gpt-image-2` и др.).
2. **Видео** — из кадра через Seedance (BytePlus ModelArk / Volcengine Ark), кадр идёт как `first_frame`.

## Как подключить

1. Открой `Video_Projects_Local.html` в Chrome или Safari.
2. Раскрой «Ключи API и параметры генерации», вставь:
   - **OpenAI API key** (`sk-…`);
   - **ModelArk API key** и **Model ID** Seedance — модель должна быть активирована в консоли ModelArk
     (например `seedance-1-5-pro-251215`, `dreamina-seedance-2-0-260128`, на Volcengine — `doubao-seedance-…`).
3. Заполни «Общий стиль кадров», при желании добавь **фото товара** — тогда все кадры строятся по нему.
4. В каждой сцене: «Сгенерировать кадр» → «Сделать видео». Или кнопки «Кадры для всех сцен» / «Видео для всех сцен с кадром».
5. «Скачать кадры и видео .zip» — все файлы ролика одним архивом для Resolve.

Ключи хранятся только в этом браузере и не попадают в JSON-экспорт/.drt.
Кадры и видео сохраняются в браузере (IndexedDB) и переживают перезагрузку страницы.

## Если «Нет соединения» (обычно у Seedance)

Браузер может блокировать прямые запросы к API (CORS). Тогда запусти рядом с HTML:

- двойной щелчок по **`Запустить AI-сервер.command`**, или
- в Терминале: `python3 ai_server.py`

и нажми в странице «Проверить соединение» — бейдж сменится на «Через локальный AI-сервер».
Сервер слушает только `127.0.0.1:8787`, нужен только стандартный Python 3.
Ключи можно задать и переменными окружения `OPENAI_API_KEY` / `ARK_API_KEY`.
