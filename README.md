# Video Projects · генератор рекламных роликов

`Video_Projects_Local.html` — локальный пошаговый генератор рекламного ролика для продукта
с экспортом титров в DaVinci Resolve (.drt).

## Вкладка «Настройки»

- OpenAI API key, модель для изображений (GPT Image 2 / 1.5 / 1 / 1 mini или свой ID), модель для анализа фото (vision).
- ModelArk API key, платформа, модель Seedance: 2.0, 2.0 Fast, 2.0 Mini (или свой Model ID).
- Видео: модель Seedance, разрешение (480p / 720p / 1080p), звук (с ним или без), длительность — с оценкой
  токенов и цены одного ролика. Текущие параметры видны над сценами.
- Формат кадра (9:16 / 16:9 / 1:1) и качество картинок.
- Баланс и расходы Seedance: сумма пакета и цена за 1 млн токенов по моделям. Приложение вычитает
  стоимость каждого готового видео по числу токенов из ответа Seedance (ключ ModelArk не даёт
  прочитать баланс аккаунта, поэтому это учёт приложения — сверяй с консолью BytePlus).
- Общий стиль кадров и шаблоны промптов (можно править и вернуть по умолчанию).
- Всё сохраняется сразу и подставляется при следующем открытии; есть кнопка «Сбросить настройки».
- «Проверить соединение» и статус локального AI-сервера.

Ключи хранятся только в этом браузере и не попадают в JSON, перенос и .drt.

## Вкладка «Генератор»

1. **Данные ролика:** скрипт, до 10 фото продукта (перетаскиванием или выбором файлов), до 10 необязательных референсов окружения,
   ссылка на товар на Amazon (необязательно) → **«Начать»**.
2. Приложение само:
   - если есть ссылка на Amazon — берёт оттуда название, характеристики и размеры (через локальный AI-сервер,
     а без него — через веб-поиск OpenAI); данные можно поправить;
   - анализирует все фото vision-моделью → **«Описание продукта»**: назначение, обстановка, цвета, материалы,
     форма, пропорции, примерный размер в см, как продукт держат или ставят, логотип,
     известные детали (точно видны на фото, с указанием где) и неизвестные (не видны или непонятны),
     8–12 сценариев использования, «мир вокруг продукта» (связанные предметы, занятия, места, эпоха). Всё можно поправить вручную —
     особенно размер и назначение;
   - разбивает скрипт на сцены, как для DaVinci;
   - делает раскадровку всех сцен одним запросом (ощущение, продукт в кадре или нет, локация, кто в кадре,
     действие, план, ракурс, свет). Продукт не обязателен в каждой сцене: сцены про связанное (аксессуары,
     занятия, эпоху) можно показать без него; продукт есть минимум в половине сцен и в последней, без него
     подряд не больше двух сцен. «Продукт в кадре» можно переключить в карточке сцены;
     без повторов: разные ситуации, планы, люди, локации; продукт всегда в реальной обстановке;
     по желанию можно остановиться после раскадровки и проверить её;
   - кадр каждой сцены строится так: только известные детали, один цельный кадр (без сплит-скрина и коллажей);
     если сцена про неизвестную деталь — безопасный вариант: предмет рядом, результат действия или продукт
     целиком без этой функции. План кадра можно поправить в сцене;
   - генерирует картинки по общему шаблону ({product}, {size}, {known_features}, {unknown_features},
     {scene_text}, {shot_plan}, {environment}, {style}): фото продукта
     идут как референсы, плюс 1–2 самых подходящих к сцене референса окружения.
3. **Сцены:** текст титра · картинка · видео. «Начать» каждый раз пересоздаёт всё заново (после подтверждения);
   отдельные сцены переделываются без «Начать»:
   - «Перегенерировать» + «Что изменить»: отметь сцены и нажми «Перегенерировать отмеченные (N)» или
     «Сгенерировать заново» в сцене. С текстом правки модель меняет текущую картинку по запросу,
     без текста — придумывает новый вариант, не похожий на остальные сцены.
   - История версий: стрелки ← → под картинкой, у каждой версии своё видео.
   - «Загрузить свою картинку» (или перетащить файл на картинку) — своя картинка встаёт новой версией сцены.
   - Под видео — поле «Пожелания к видео» / «Что изменить в видео»: текст идёт в промпт Seedance
     главным указанием (русский переводится на английский) и сохраняется подписью к видео.
   - «Сгенерировать заново» — новая картинка (видео сцены сбрасывается).
   - «Сгенерировать видео» — Seedance, картинка идёт как первый кадр. Промпт выбирается по тому, есть ли люди на картинке.
   - Под каждым видео: модель, разрешение, длительность, токены и стоимость.
   - «Промпты сцены» — финальные промпты картинки и видео, можно поправить до отправки.
4. «Скачать кадры и видео .zip» и «Экспорт в DaVinci · .drt».

Проект сохраняется автоматически: скрипт, фото, анализ, раскадровка, тексты сцен, «Что изменить», картинки,
видео и история версий. Данные проекта лежат в localStorage с копией в IndexedDB (медиа — в IndexedDB);
после закрытия приложение открывается в том же состоянии и ничего не генерирует само.

## Восстановление и несколько вкладок

- Открывай приложение в одной вкладке. Если проект изменён в другой вкладке или другой копии приложения,
  появится предупреждение, и эта вкладка перестанет сохранять, чтобы не затереть новую работу.
- «Настройки» → «Восстановление»: найти картинки, видео и фото, которые лежат в браузере, но не привязаны
  к проекту, и вернуть их в сцены; посмотреть автоматические копии проекта (до 30, не чаще раза в 3 минуты)
  и добавить ролики из копии.
- «Очистить неиспользуемые файлы» удаляет только то, что не нужно ни проекту, ни сохранённым копиям.

## Лица людей и Seedance 2.0 / 2.5

Seedance 2.0 и 2.5 не принимают картинки с реалистичными лицами («may contain real person»), даже
сгенерированные. Поэтому в настройках по умолчанию включено «Без чётких лиц людей»: раскадровка и промпт
показывают людей со спины, вполоборота, издалека, в расфокусе или в тени. Если Seedance всё же отклонил кадр,
сцена сама отмечается «Перегенерировать» с подсказкой в «Что изменить».

## Видео: из текста с картинкой-референсом

По умолчанию видео строится по одному общему промпту для всех сцен («Настройки» → «Видео · Seedance» →
«Общий промпт видео»), в который подставляются план кадра, текст, ощущение и движение сцены; картинка сцены
идёт в Seedance как референс («Image 1», роль `reference_image`). Поле «Дополнение к промпту видео» под видео
в сцене добавляется в конец общего промпта и сохраняется для следующих генераций этой сцены. Если продукт в кадре, добавляются до 3 фото
продукта («Image 2–4»). Старый режим «картинка — первый кадр» выбирается в «Настройки» → «Как делать видео».
Seedance 2.0 Mini и Fast не делают 1080p — только 480p и 720p.

## Люди с лицами: библиотека AI-портретов BytePlus (пошагово)

Seedance 2.x не принимает картинки с реалистичными лицами. Официальный путь BytePlus для сгенерированных людей —
зарегистрировать картинку в «Private virtual portrait library» как AI-портрет и передать её ссылкой `asset://`.
Приложение делает это само, если всё настроено:

1. **Ключи аккаунта (не ключ ModelArk).** Консоль BytePlus → IAM → Users → создать пользователя (или открыть
   своего) → вкладка ключей → *Create Access Key*. Сохрани **Access Key ID** (`AKLT…`) и **Secret Access Key** —
   секрет показывается один раз.
2. **Права.** Тому же пользователю: IAM → Permissions → добавить политики **ArkFullAccess** (библиотека
   портретов в ModelArk) и **TOSFullAccess** (хранилище файлов).
3. **Бакет — не обязателен.** На личном аккаунте BytePlus сервис TOS недоступен («only available through
   enterprise certification»). Без бакета приложение передаёт картинку прямо в запросе регистрации;
   «Проверить доступ» регистрирует маленькую тестовую картинку и покажет, принимает ли это BytePlus.
   Если аккаунт компании и TOS доступен — можно указать бакет (Private, регион ap-southeast-1).
4. **Библиотека портретов.** Консоль ModelArk → раздел ассетов (*My assets* → *Virtual Portrait*). Если
   консоль просит принять условия или включить доступ — прими. Бесплатный уровень: до 50 портретов
   и 3 регистрации в минуту.
5. **Приложение.** Запусти «Запустить AI-сервер.command» (без сервера библиотека не работает) → «Настройки» →
   «Люди в видео: библиотека AI-портретов BytePlus»: включи галочку, вставь Access Key ID и Secret Access Key
   (бакет — только если он есть). Адрес TOS (`tos-ap-southeast-1.bytepluses.com`), регион (`ap-southeast-1`) и проект
   (`default`) менять не нужно, если ты не меняла их в консоли.
6. Нажми **«Проверить доступ»**: должно быть «доступ есть ✓» и «Регистрация без бакета: работает ✓»
   (или «запись работает ✓», если указан бакет). Если нет — текст ошибки
   подскажет, что исправить (ключи, права или имя бакета).
7. Можно выключить «Без чётких лиц людей» — приложение предложит это само.

**Если BytePlus не принимает картинку без ссылки** — ручной путь, без бакета и без галочки: скачай картинку
сцены, загрузи её в консоли (Model Playground → My assets → Virtual Portrait → Manage assets), скопируй
Asset ID и вставь в сцене в поле «Свой Asset ID из BytePlus» (под видео). Видео этой версии картинки пойдёт
в Seedance как `asset://`.

Дальше «Сгенерировать видео» для сцены с людьми сначала регистрирует картинку (до минуты; при нескольких
сценах подряд — дольше из-за лимита 3 в минуту), потом отправляет её в Seedance как `asset://`. После готового
видео портрет удаляется из библиотеки, чтобы не упереться в лимит 50 (можно отключить).

Что не проверено: этот путь BytePlus подтвердил для Seedance 2.5 с ролью `reference_image`; для 2.0 — нет.
Если Seedance 2.0 откажет со ссылкой `asset://`, напиши текст ошибки.

## Продукт не меняется

Во всех промптах с продуктом: продукт нельзя менять или искажать, надписи и особенно логотип
воспроизводятся точно как на фото (текст логотипа из анализа подставляется дословно).

## Если «Нет соединения» (обычно у Seedance)

Запусти рядом с HTML **`Запустить AI-сервер.command`** (или `python3 ai_server.py`) и нажми
«Проверить соединение» в настройках. Сервер слушает только `127.0.0.1:8787`, нужен только Python 3.
Ключи можно задать и переменными окружения `OPENAI_API_KEY` / `ARK_API_KEY`.
