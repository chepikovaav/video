# Video Projects · генератор рекламных роликов

`Video_Projects_Local.html` — локальный пошаговый генератор рекламного ролика для продукта
с экспортом титров в DaVinci Resolve (.drt).

## Ролики во вкладках (версия 10.5)

Внутри оформления (NXA) каждый ролик — своя вкладка под заголовком; «＋ Новый ролик» добавляет вкладку,
остальные вкладки со всеми картинками, видео и музыкой остаются как есть.

Каждый ролик полностью отделён от других: у его сцен свои номера (копия, импорт и восстановление из копии
получают новые), а пока идёт «Начать» или другая генерация картинок, вкладки не переключаются — новые сцены
попадают только в тот ролик, где нажали «Начать». Крестик «×» на вкладке удаляет ролик (после подтверждения;
единственный ролик в проекте не удаляется). Копия библиотеки до удаления остаётся в «Настройки» → «Восстановление».
Новый ролик берёт логотип, водяной знак и слоган из других роликов этого проекта — от логотипа зависят заставка,
длина ролика и музыки. Если в ролике логотип поменять или убрать вручную, это остаётся только в нём.

## Версии и свои файлы в сцене

- Картинка: ‹ › — версии; ⤒ рядом с «Сгенерировать заново» — своя картинка (или перетащи файл на картинку).
- Видео: ‹ › — версии видео этой картинки (до 8); ⤒ — своё видео (или перетащи файл на видео).

## Оформление (версия 10)

- Тема: «Тема: авто» вверху справа — как в macOS (тёмная / светлая); нажатием — светлая, тёмная, снова авто.
- Зелёный — только главное: «Начать», «Сгенерировать заново» под картинкой и под видео, «Готово», выбранный
  масштаб продукта и номера шагов и сцен.
- Карточка сцены: три колонки с выровненными строками — превью, строка с описанием и ценой справа, одна
  настройка (масштаб продукта / модель видео), «Сгенерировать заново» со скачиванием рядом, аккордеон
  («Выделения и переносы», «Что изменить», «Дополнение к промпту»; точка — внутри есть правка). Текст правится
  по кнопке «Править текст». Внизу одна строка: длительность, тайминг и справа «Время, с» и «Авто».

## Вкладка «Настройки»

- OpenAI API key, модель для изображений (GPT Image 2 / 1.5 / 1 / 1 mini или свой ID), модель для анализа фото (vision).
- ModelArk API key, платформа, модель Seedance: 2.0, 2.0 Fast, 2.0 Mini (или свой Model ID).
- Higgsfield API key (`KEY_ID:KEY_SECRET`, open.higgsfield.ai → API Keys) — видео Wan, MiniMax H3, Kling
  и Seedance через Higgsfield. У API свой долларовый баланс (open.higgsfield.ai → Billing), кредиты подписки сайта на него не тратятся.
  Работает только через AI-сервер; картинка сцены идёт первым кадром. Поле «Своя модель Higgsfield» — путь модели из
  docs.higgsfield.ai, если нужной модели нет в списке.
  Цены в меню моделей — текущие: приложение спрашивает у Higgsfield бесплатную оценку цены для каждой модели и
  длины сцены (раз в 12 часов, ничего не генерируется). Без знака «≈» — цена от Higgsfield; с «≈» — по прайсу из
  расходов аккаунта, если Higgsfield не ответил.
- Видео: модель Seedance, разрешение (480p / 720p / 1080p), звук (с ним или без), длительность — с оценкой
  токенов и цены одного ролика. Текущие параметры видны над сценами.
- Формат кадра (9:16 / 16:9 / 1:1) и качество картинок.
- Баланс и расходы Seedance: сумма пакета и цена за 1 млн токенов по моделям. Приложение вычитает
  стоимость каждого готового видео по числу токенов из ответа Seedance (ключ ModelArk не даёт
  прочитать баланс аккаунта, поэтому это учёт приложения — сверяй с консолью BytePlus).
- Общий стиль кадров и шаблоны промптов (можно править и вернуть по умолчанию).
- Всё сохраняется сразу и подставляется при следующем открытии; есть кнопка «Сбросить настройки».
- «Проверить соединение» и статус локального AI-сервера.

Ключи из файла `.env` рядом с `ai_server.py` берутся автоматически, и их поля скрываются (см. ниже).
Введённые на странице ключи хранятся только в этом браузере и не попадают в JSON, перенос и .drt.

## Вкладка «Генератор»

1. **Данные ролика:** скрипт, до 10 фото продукта (перетаскиванием или выбором файлов), до 10 необязательных референсов окружения,
   ссылка на товар на Amazon (необязательно) → **«Начать»**.
2. Приложение само:
   - если есть ссылка на Amazon — берёт оттуда название, характеристики и размеры (через локальный AI-сервер,
     а без него — через веб-поиск OpenAI); данные можно поправить;
   - анализирует все фото vision-моделью → **«Описание продукта»**: назначение, обстановка, цвета, материалы,
     форма, пропорции, примерный размер в см, как продукт держат или ставят, логотип,
     известные детали (точно видны на фото, с указанием где) и неизвестные (не видны или непонятны),
     свойства и преимущества (для каждого 2–3 способа показать — с продуктом и без него),
     «перед и зад, рабочая часть» (где линза или динамики и куда они направлены, на каком фото какая сторона) и
     «подключение» (какой провод и откуда выходит) — если они заполнены, раскадровка и промпт картинки добавляют по
     строке: рабочая часть смотрит туда, где действие (линза на стену), а у видимой задней панели есть провод;
     8–12 сценариев использования, «мир вокруг продукта» (связанные предметы, занятия, места, эпоха). Всё можно поправить вручную —
     особенно размер и назначение;
   - разбивает скрипт на сцены, как для DaVinci;
   - делает раскадровку всех сцен одним запросом: какое свойство показывает сцена и как картинка его доказывает,
     ощущение, масштаб продукта (нет / близко / средне / далеко), локация, кто в кадре, действие, ракурс, свет.
     Продукт не обязателен в каждой сцене: сцены про связанное (аксессуары, занятия, эпоху) можно показать без него.
     Масштаб чередуется: у соседних сцен разный; от 4 сцен каждый вариант хотя бы раз; ни один не больше трети сцен;
     продукт в кадре минимум в половине сцен; без него подряд не больше двух; в последней — «близко» или «средне».
     Приложение само проверяет эти правила: при нарушениях раскадровка один раз уходит модели на исправление,
     а что осталось — показывается в строке статуса. Масштаб можно переключить в карточке сцены («Продукт»);
     без повторов: разные ситуации, планы, люди, локации; продукт всегда в реальной обстановке;
     по желанию можно остановиться после раскадровки и проверить её;
   - кадр каждой сцены строится так: только известные детали, один цельный кадр (без сплит-скрина и коллажей);
     если сцена про неизвестную деталь — безопасный вариант: предмет рядом, результат действия или продукт
     целиком без этой функции. План кадра можно поправить в сцене;
   - генерирует картинки по общему шаблону ({product}, {size}, {known_features}, {unknown_features},
     {scene_text}, {property}, {how_shown}, {feeling}, {shot_plan}, {environment}, {other_scenes}, {user_feedback},
     {style}); блок о продукте выбирается по масштабу — со строкой FRAMING для «близко / средне / далеко»
     или «без продукта». Фото продукта идут как референсы только в сценах с продуктом,
     плюс 1–2 самых подходящих к сцене референса окружения.
3. **Сцены:** текст титра (под ним — какое свойство показывает сцена) · картинка (под ней переключатель
   «Продукт: нет / близко / средне / далеко») · видео. «Начать» каждый раз пересоздаёт всё заново (после подтверждения);
   отдельные сцены переделываются без «Начать»:
   - «Перегенерировать» + «Что изменить»: отметь сцены и нажми «Перегенерировать отмеченные (N)» или
     «Сгенерировать заново» в сцене. С текстом правки модель меняет текущую картинку по запросу,
     без текста — придумывает новый вариант, не похожий на остальные сцены.
   - История версий: стрелки ← → под картинкой, у каждой версии своё видео.
   - «Загрузить свою картинку» (или перетащить файл на картинку) — своя картинка встаёт новой версией сцены.
   - Под видео — поле «Пожелания к видео» / «Что изменить в видео»: текст идёт в промпт Seedance
     главным указанием (русский переводится на английский) и сохраняется подписью к видео.
   - «Сгенерировать заново» — новая картинка (видео сцены сбрасывается).
   - «Сгенерировать видео» — Seedance, картинка идёт как первый кадр. Промпт выбирается по тому, есть ли люди на картинке.
   - Над кнопкой «Сгенерировать видео» — выбор модели для этой сцены с ценой ролика: Higgsfield — Wan 3.0, MiniMax H3,
     Wan 2.7, Kling 4.0, Kling 4.0 Flash, Kling 3.0 Standard / Pro, Seedance 2.0 (все — 720p без звука;
     MiniMax H3 только 2K, Kling 3.0 Pro — 1080p); BytePlus — Seedance 2.0 / Fast / Mini. По умолчанию — модель из настроек.
   - Под каждым видео: модель, разрешение, длительность, токены и стоимость. Для Higgsfield — цена, которую он назвал при отправке.
   - «Промпты сцены» — финальные промпты картинки и видео, можно поправить до отправки.
4. **«Собрать в DaVinci»** и **«Отрендерить»** (см. ниже), «Скачать кадры и видео .zip», «Экспорт в DaVinci · .drt» (только титры) и **«Экспорт в DaVinci с видео»** (см. ниже).

Проект сохраняется автоматически: скрипт, фото, анализ, раскадровка, тексты сцен, «Что изменить», картинки,
видео и история версий. Данные проекта лежат в localStorage с копией в IndexedDB (медиа — в IndexedDB);
после закрытия приложение открывается в том же состоянии и ничего не генерирует само.

## Восстановление и несколько вкладок

- Открывай приложение в одной вкладке. Если проект изменён в другой вкладке или другой копии приложения,
  появится предупреждение, и эта вкладка перестанет сохранять, чтобы не затереть новую работу.
- «Настройки» → «Восстановление»: найти картинки, видео и фото, которые лежат в браузере, но не привязаны
  к проекту, и вернуть их в сцены; посмотреть автоматические копии проекта (до 30, не чаще раза в 3 минуты)
  и добавить ролики из копии.
- «Очистить неиспользуемые файлы» удаляет только то, что не нужно ни проекту, ни сохранённым копиям.

## Картинки: киношный кадр, лица видны

С версии 9.8 люди на картинках с лицами, как актёры в кино: видна эмоция, смотрят на своё действие, друг на
друга или за кадр, но не в объектив. В каждом кадре — одно понятное действие; малая глубина резкости (фон мягко
размыт); спокойные поверхности без мелких рябящих узоров (полоски, сетки, жалюзи, листва); «воздух» — около трети
кадра спокойное пустое место; продукт в кадре резкий, ничем не закрыт, логотипом к камере.

Видео сцен с лицами делай моделями Higgsfield (Kling, Wan 3.0, MiniMax H3). Seedance 2.0 и 2.5 через BytePlus
не принимают картинки с реалистичными лицами («may contain real person») — для них в «Сцены с людьми» есть
режим «без чётких лиц» (люди со спины, вполоборота, издалека). Если BytePlus отклонил кадр с лицом,
приложение подскажет выбрать модель Higgsfield.

## Nano Banana (Google Gemini) — запасной генератор

«Настройки» → «Google Gemini · Nano Banana»: ключ из Google AI Studio (aistudio.google.com → Get API key; для
оплаты по факту подключи Billing). По умолчанию порядок «OpenAI, а если закончились деньги или ошибка доступа —
Nano Banana»: при ошибке квоты/оплаты/доступа OpenAI приложение до конца сессии переходит на Gemini —
картинки, анализ, раскадровка, описание кадров, перевод и поиск по Amazon. Можно выбрать «Только Gemini».
Цены за картинку (осень 2026, проверяй на ai.google.dev/gemini-api/docs/pricing): Nano Banana 2 ≈ $0,034–0,05,
Pro ≈ $0,134, 2.5 ≈ $0,039.

## DaVinci: подложка под титрами

«Настройки» → «DaVinci · подложка под титрами»: цвет и непрозрачность (по умолчанию чёрный, 25%). Подложка
встраивается внутрь каждого титра (Fusion: Background + Merge под текстом), поэтому в экспортированном .drt
она лежит поверх видео и под текстом на всё время титров. Видна и в превью.

## Водяной знак

В «Данные ролика» → «Логотип» два места: «Заставка» (крупно на финальном кадре) и «Водяной знак» (маленький
поверх видео). Положение, размер и непрозрачность — «Настройки» → «Водяной знак». Знак виден в превью и
попадает в архив .zip как «водяной знак.png»; в .drt его нет — в DaVinci положи файл на верхнюю дорожку.

## Превью ролика и финальная заставка

Блок «4 Превью ролика»: видео сцен (или картинки, если видео ещё нет) по времени титров, подложка, титры и
финальная заставка; полоса снизу — сцены, по ней можно перематывать. Финальная заставка: логотип (загружается
в «Данные ролика») и подпись на цветном фоне, длительность и фон — в настройках. В архив .zip она попадает как
«99 финал.png» в формате кадра — в DaVinci поставь её в конец таймлайна.

## Видео: из текста с картинкой-референсом

По умолчанию видео строится по одному общему промпту для всех сцен («Настройки» → «Видео · Seedance» →
«Общий промпт видео»), в который подставляются план кадра, текст, ощущение и движение сцены; картинка сцены
идёт в Seedance как референс («Image 1», роль `reference_image`). Поле «Дополнение к промпту видео» под видео
в сцене добавляется в конец общего промпта и сохраняется для следующих генераций этой сцены. Если продукт в кадре, добавляются до 3 фото
продукта («Image 2–4»). Старый режим «картинка — первый кадр» выбирается в «Настройки» → «Как делать видео».
Seedance 2.0 Mini и Fast не делают 1080p — только 480p и 720p.

## Люди в видео: видео повторяет картинку (по умолчанию)

Картинка сцены уходит в Seedance первым кадром, поэтому видео повторяет её. Seedance 2.x не принимает картинки
с реалистичными лицами, поэтому Nano Banana рисует людей без чётких лиц (со спины, вполоборота, в профиль,
издалека, в расфокусе, в тени). Если Seedance всё же увидит лицо, приложение само перерисует картинку без лиц
(остальное как было) и повторит видео. Во всех промптах видео продукт стоит как на картинке — лицевой стороной
с логотипом к камере, не поворачивается.

## Люди с лицами в видео (режим «описывать текстом»)

Seedance 2.x не принимает входные картинки с реалистичными лицами, но сам рисует людей с лицами по тексту.
Поэтому для сцен с людьми картинка не отправляется: модель анализа подробно описывает кадр (люди, одежда,
позы, место, свет, ракурс), описание встаёт в общий промпт видео, а фото продукта идут референсами.
Видео получается близким к картинке, но не её копией. Режим: «Настройки» → «Люди в видео» → «Сцены с людьми».

## Библиотека AI-портретов BytePlus (нужна платная подписка Advanced Creation Rights)

Seedance 2.x не принимает картинки с реалистичными лицами. Официальный путь BytePlus для сгенерированных людей —
зарегистрировать картинку в «Private virtual portrait library» как AI-портрет и передать её ссылкой `asset://`.
Приложение делает это само, если всё настроено:

1. **Ключи аккаунта (не ключ ModelArk).** Консоль BytePlus → IAM → Users → создать пользователя (или открыть
   своего) → вкладка ключей → *Create Access Key*. Сохрани **Access Key ID** (`AKLT…`) и **Secret Access Key** —
   секрет показывается один раз.
2. **Права.** Тому же пользователю: IAM → Permissions → добавить политики **ArkFullAccess** (библиотека
   портретов в ModelArk) и **TOSFullAccess** (хранилище файлов).
3. **Бакет — не обязателен.** На личном аккаунте BytePlus сервис TOS недоступен («only available through
   enterprise certification»). Без бакета приложение передаёт картинку прямо в запросе регистрации;
   «Проверить доступ» регистрирует маленькую тестовую картинку и покажет, принимает ли это BytePlus.
   Если аккаунт компании и TOS доступен — можно указать бакет (Private, регион ap-southeast-1).
4. **Библиотека портретов.** Консоль ModelArk → раздел ассетов (*My assets* → *Virtual Portrait*). Если
   консоль просит принять условия или включить доступ — прими. Бесплатный уровень: до 50 портретов
   и 3 регистрации в минуту.
5. **Приложение.** Запусти «Запустить AI-сервер.command» (без сервера библиотека не работает) → «Настройки» →
   «Люди в видео: библиотека AI-портретов BytePlus»: включи галочку, вставь Access Key ID и Secret Access Key
   (бакет — только если он есть). Адрес TOS (`tos-ap-southeast-1.bytepluses.com`), регион (`ap-southeast-1`) и проект
   (`default`) менять не нужно, если ты не меняла их в консоли.
6. Нажми **«Проверить доступ»**: должно быть «доступ есть ✓» и «Регистрация без бакета: работает ✓»
   (или «запись работает ✓», если указан бакет). Если нет — текст ошибки
   подскажет, что исправить (ключи, права или имя бакета).
7. Можно выключить «Без чётких лиц людей» — приложение предложит это само.

**Если BytePlus не принимает картинку без ссылки** — ручной путь, без бакета и без галочки: скачай картинку
сцены, загрузи её в консоли (Model Playground → My assets → Virtual Portrait → Manage assets), скопируй
Asset ID и вставь в сцене в поле «Свой Asset ID из BytePlus» (под видео). Видео этой версии картинки пойдёт
в Seedance как `asset://`.

Дальше «Сгенерировать видео» для сцены с людьми сначала регистрирует картинку (до минуты; при нескольких
сценах подряд — дольше из-за лимита 3 в минуту), потом отправляет её в Seedance как `asset://`. После готового
видео портрет удаляется из библиотеки, чтобы не упереться в лимит 50 (можно отключить).

Что не проверено: этот путь BytePlus подтвердил для Seedance 2.5 с ролью `reference_image`; для 2.0 — нет.
Если Seedance 2.0 откажет со ссылкой `asset://`, напиши текст ошибки.

## Продукт не меняется

Во всех промптах с продуктом: продукт нельзя менять или искажать, надписи и особенно логотип
воспроизводятся точно как на фото (текст логотипа из анализа подставляется дословно).

## Музыка (шаг 4)

ElevenLabs Music пишет трек ровно по длине ролика (сцены + финал − полсекунды перехода), без слов.
Ключ — «Настройки» → «Музыка · ElevenLabs» (или ELEVENLABS_API_KEY в .env); музыка через API только на платном
плане, для коммерческих роликов — Starter и выше; ≈ $0.15 за минуту. Описание собирается из ролика: продукт,
настроение сцен из раскадровки и стиль из списка; его можно поправить (по-английски, без названий групп и песен).
Трек играет в превью и при «Собрать в DaVinci» встаёт на A1 с начала таймлайна; на A1 больше ничего нет —
звук из сгенерированных видео не ставится.

## Собрать в DaVinci → посмотреть → отрендерить

Кнопка **«Собрать в DaVinci»** внизу страницы. AI-сервер на этом компьютере сам открывает DaVinci Resolve
(если он закрыт), создаёт новый проект «Название ГГГГ-ММ-ДД ЧЧ-ММ» (24 кадра/с, размер по «Формату кадра»)
и собирает таймлайн в виде эталонного ролика. Проект остаётся открытым — посмотри его, при желании поправь.
Потом кнопка **«Отрендерить»** (сама откроет этот проект в DaVinci, если открыт другой; видео сцен и музыку,
которые ты переделала в приложении после сборки, сама заменит в проекте — монтаж и правки в DaVinci остаются) рендерит этот проект (с твоими правками) в MP4 в
«Фильмы → Video Projects → Название → DaVinci …»:

- V1 — видео сцен встык, без их собственного звука; видео другой формы (например 3:2) заполняет кадр с обрезкой краёв;
  светлые сцены, где белый текст плохо читается (светлый или пёстрый фон в зоне титров), затемняются кривой —
  белая точка ≈ 85 % («Настройки» → «DaVinci · плёночный вид» → «Затемнять светлые сцены»), каждое ровно по длине своего титра (последнее — ещё полсекунды под переходом).
  Видео генерируются по длине титра; если файл всё же короче, DaVinci плавно замедляет его (optical flow);
- V2 — adjustment layer из эталона: FilmConvert Nitrate (зерно 50, мягкость 6.2; Exposure −0.4 и Temp 10 — как настроено
  в DaVinci, меняются в «Настройки» → «DaVinci · плёночный вид») и Gaussian Blur 0.115;
- V3 — титры;
- V4 — водяной знак (логотип «Водяной знак»): 20 %, правый нижний угол, 70 %, гаснет перед финалом;
- V5 — финал (логотип «Заставка»): фон цвета финала из настроек, логотип 34 % (как в эталоне), пульсация «как на сабвуфере» — +1.8 % за 2 кадра и быстро назад, каждые 0.5 с,
  вход через Checker Wipe (1 с).

Превью в приложении (шаг «Превью ролика») показывает ролик так же: водяной знак на том же месте и того же
размера, финал с логотипом 34 % и пульсацией, переход — плавное наложение (в DaVinci — Checker Wipe),
плёночный вид — приблизительно.

Нужно один раз: DaVinci Resolve → Preferences → System → General → **External scripting using: Local**,
плагин FilmConvert Nitrate установлен, DaVinci открыт. Текущий проект DaVinci сохраняется и закрывается —
открывается новый.

## Экспорт в DaVinci с видео

`.drt` хранит видео в закрытом двоичном формате, поэтому таймлайн с видео собирает сам DaVinci Resolve:

1. Нажми **«Экспорт в DaVinci с видео»** (нужен запущенный AI-сервер на этом компьютере).
   Сервер создаст папку `~/Movies/Video Projects/<название ролика>/` (откроется в Finder):
   видео сцен (`scene-01.mp4`…; если видео нет — картинка сцены), финальная заставка, `.drt` с титрами
   и скрипт `Video Projects — собрать таймлайн.lua`. Скрипт сразу кладётся в меню DaVinci Resolve.
2. В DaVinci Resolve открой проект и выбери **Workspace → Scripts → «Video Projects — собрать таймлайн»**.
   Скрипт импортирует таймлайн с титрами и ставит видео сцен на дорожку V1 точно под титры.
   Если видео короче сцены, оно не растягивается. Если пункта нет в меню — перезапусти Resolve.

Папку экспорта можно сменить в `.env`: `AI_EXPORT_DIR=/путь/к/папке`.

## Обновление

Двойной щелчок по **`Запустить AI-сервер.command`** сам скачивает свежую версию с GitHub и, если старый
AI-сервер ещё запущен, останавливает его и запускает новый. Ничего вводить в Терминал не нужно.

## Если «Нет соединения» (обычно у Seedance)

Запусти рядом с HTML **`Запустить AI-сервер.command`** (или `python3 ai_server.py`) и нажми
«Проверить соединение» в настройках. Сервер слушает только `127.0.0.1:8787`, нужен только Python 3.

## Ключи в файле `.env`

Положи ключи в файл `.env` рядом с `ai_server.py`, и их не придётся вводить на странице:

    cd ~/video && cp .env.example .env && open -e .env

Впиши нужные ключи (`OPENAI_API_KEY`, `GEMINI_API_KEY`, `ARK_API_KEY`, при необходимости `BYTEPLUS_ACCESS_KEY` / `BYTEPLUS_SECRET_KEY`), сохрани и перезапусти AI-сервер. Окно сервера покажет,
какие ключи взяты, а поля этих ключей в «Настройках» скроются. Ключ из `.env` важнее введённого на странице.
`.env` есть в `.gitignore` и в git не попадает. В Finder файлы с точкой скрыты: показать их — ⌘⇧. .

## ChatGPT через Codex (без ключа OpenAI)

Анализ фото, план сцен и картинки могут идти через Codex по подписке ChatGPT (Plus/Pro/Business):

    npm i -g @openai/codex      # или: brew install codex
    codex login                 # выбрать «Sign in with ChatGPT»

Перезапусти AI-сервер. В «Настройках» → «Как работать с ChatGPT» выбери «Codex» (или «Авто»: Codex
включится, если ключа OpenAI нет). Порядок «OpenAI → Nano Banana» тоже работает: если лимит Codex
закончился, картинки пойдут через Gemini. Картинка через Codex — 1–5 минут и тратит лимит подписки;
модель выбирает сам Codex, размер — подсказка в промпте. Работает только через AI-сервер.

## Сервер: Ubuntu + Cloudflare

Схема: `браузер → Cloudflare (Access + HTTPS) → Cloudflare Tunnel → 127.0.0.1:8787 (ai_server.py)`.
Порты на сервере открывать не нужно, nginx и сертификаты не нужны.

1. **Файлы на сервер** (или `git clone`):
   `scp -r Video_Projects_Local.html ai_server.py deploy user@SERVER:~/video/`
2. **AI-сервер как служба:** `cd ~/video && sudo bash deploy/install.sh https://video.ваш-домен.com`
   (ставит python3, кладёт файлы в `/opt/video`, создаёт `/etc/video-ai.env` и службу `video-ai`).
3. **Туннель:** Cloudflare → Zero Trust → Networks → Tunnels → Create tunnel (cloudflared) →
   выполнить на сервере показанную команду `sudo cloudflared service install …` →
   Public hostname: `video.ваш-домен.com`, Service: `HTTP` · `localhost:8787`.
4. **Закрыть доступ (обязательно):** Zero Trust → Access → Applications → Add → Self-hosted →
   домен `video.ваш-домен.com`, политика Allow → Emails: свои адреса. Вход по коду из почты.
5. Открыть `https://video.ваш-домен.com` → «Настройки» → «Проверить соединение».

Обновить после правок: снова `sudo bash deploy/install.sh https://video.ваш-домен.com`
(`/etc/video-ai.env` не перезаписывается). Логи: `journalctl -u video-ai -f`.

Ключи можно вводить в браузере (как локально) или прописать в `/etc/video-ai.env` —
тогда ими пользуется любой, кто прошёл Access. Cloudflare обрывает запросы дольше 100 с (ошибка 524):
Seedance это не касается, а очень тяжёлая картинка OpenAI в высоком качестве может не успеть — тогда повторить.
